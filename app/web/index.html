Servo setup

Check every joint once before driving the real robot. Connect in Bluetooth, lift the robot, then press Test on a row: the simulated joint and the real servo both move +10° and back. If the wrong part moves, change Servo; if it moves the other way, switch Direction; if it is a little off at 0°, set Offset. Then tick Verified. Changes are saved immediately.

Your first experiment
  1. Pose. Drag the joint sliders. Add a keyframe at 0 seconds.
  2. Animate. Change the time to 2 seconds, change the pose, and add another keyframe. Play or scrub the timeline.
  3. Test. Add a ramp or your own mesh. Run physics, then play the motion to test it against gravity and contacts.
  4. Adjust. Edit objects in the inspector. Use Model to edit the URDF. Reset restores the robot and obstacles.
  5. Save. Save a project JSON. Imported assets stay in this installation's data folder; keep that folder with your project.
  6. Export. Verify servo indices, directions and offsets, then download a Python script for your real Bittle.
Keyboard: F focuses the robot. Space toggles motion playback when you are outside a text field.
This is a local, single-session workbench. Multiple tabs share one simulation. Mesh imports retain geometry and use a selected surface colour; embedded textures are not imported. Metres are the default; set mesh scale to 0.001 for millimetres.
