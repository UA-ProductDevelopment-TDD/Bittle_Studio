# Saved motions

Motion packs for the Bittle Link robot console. Each `.json` file holds console buttons plus your Studio functions, already compiled for the robot.

- **Create one:** in Bittle Studio, open **Bluetooth → Console** and press **Save pack**.
- **Use one:** in Bittle Link (`launch-bittle-link.cmd`), press **Import pack** and choose it from the list.

These files are shared through GitHub with the rest of the project, so commit the packs you want your team to have.
